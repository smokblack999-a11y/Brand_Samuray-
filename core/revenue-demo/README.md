# SAMURAI Revenue — UI Demo

Standalone, dependency-free dashboard prototype for the auto-service/detailing vertical.

## Run locally
Open `index.html` in a modern browser, or serve this folder with any static HTTP server.

## Scope
- Synthetic sample leads only.
- Search and status filters.
- Click a row to cycle through statuses.
- Add a synthetic lead in the demo form.
- Summary counters are calculated in the browser.

## Explicit limitations
- No SAMURAI Core integration.
- No Telegram Bot API integration.
- No authentication or tenant isolation.
- No persistence: reloading resets the demo data.
- No real customer or payment data.
- Not suitable for public deployment or production use.

This prototype is a UI validation artifact, not a functioning SaaS product.
