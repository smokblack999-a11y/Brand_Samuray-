# NEXUS Product Surface
Primary product: Recovery Control Plane.
Core screens:
1. Incident — failure, root cause, risk, current state.
2. Recovery — attempt timeline and patch evidence.
3. Verification — sandbox/tests/CI/SHA proof.
4. Policy — Kill Critic rules and human-review boundaries.
5. Audit — immutable-looking, hash-linked evidence view.
Commercial wedge: paid pilot first; SaaS only after a real verified-recovery dataset exists.
