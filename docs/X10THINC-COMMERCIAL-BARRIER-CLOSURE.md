# X10THINC Commercial Barrier Closure

## Goal

Reduce purchase friction without overstating capability.

| Buyer barrier | Concrete response |
|---|---|
| Trust in AI changes | Separate Kill Critic gate; BLOCK/ABSTAIN are valid outcomes |
| Production access | Start read-only with a non-production repository |
| Prove value first | Free public health check, then fixed-price audit |
| Unclear product | One outcome: one failing workflow → recovery evidence |
| Demo is not reality | Deterministic lab is labelled as a fixture; external repo is the proof threshold |
| Wrong repair | Verification must pass; otherwise no VERIFIED state |
| Dangerous change | Protected paths fail closed |
| Auditability | Proof Receipt binds incident, source revision, verdict and evidence hash |
| AI uncertainty | ABSTAIN is terminal; no forced success |
| Engineer replacement concern | Position as recovery acceleration + evidence |
| Unclear ROI | Measure TIME_TO_PROOF against the customer's baseline |
| Commitment risk | Fixed pilot scope with explicit stop point |

## Funnel

PUBLIC REPO
→ FREE HEALTH CHECK
→ EXPRESS AUDIT ($300–500)
→ CI RECOVERY PILOT ($750–1,500)
→ INTEGRATION ($2k–5k+)

Commercial target: external repository → verified result → paid pilot → customer evidence.

Until external evidence exists, use **prototype / lab / pilot**, not production-scale claims.
